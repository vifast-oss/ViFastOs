#
# Định dạng TSV, 5–6 cột:
#   tên <TAB> chương trình <TAB> đối-số CLI <TAB> stdout kỳ vọng <TAB> mã thoát [<TAB> stderr chứa]
#
# - Chương trình: `vis:<nguồn>` (.vis) hoặc `vish:<nguồn>` (.vish); nguồn dùng escape \n, \t, \r, \\.
#   `{tmp}` = thư mục tạm riêng của ca (cwd khi chạy); `{host}` = thư mục test/host.
# - Đối số CLI: tách bằng khoảng trắng; `repeat=N` = chạy N lần **mỗi** đường (determinism), không truyền cho `vis`.
# - Harness luôn tạo fixture: in.txt, empty.txt, utf8.txt, crlf.txt, space name.txt, tệp-việt.txt,
#   big.txt (64 KiB), sub/long.txt, list/{a,b,c}.txt, list/sub/, root/in.txt, ngoai.txt, a/a.txt, b/b.txt.
# - Mỗi ca PHẢI có stdout khác rỗng hoặc mã thoát khác 0 (không có ca 'xanh vì không kiểm gì').
#
