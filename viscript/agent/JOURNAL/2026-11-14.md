## ST-53 — `to json` + hợp nhất hai `sort_by`

- **`to json`** (nợ lõi #1): trước đây **chưa có stage**, `to` chạy như chương trình ngoài (`VS0501`).
  Nay là **stage lệnh** hạ thành `Call(std.json.encode, [prev])`; `--pretty` ⇒ `std.json.encode_pretty`;
  **không cần `use std.json`** (shell sugar tự phân giải, như Agent 0 chốt); thiếu pipe/cờ lạ ⇒
  **`VS0602`** nêu rõ. Bản ghi **ẩn danh** (`select pid, name`) encode đúng **khoá trường + thứ tự**
  (serializer bỏ tên bản ghi) ⇒ **không** cần "tên tổng hợp", **không** đụng `Type::Any`.
  Chi tiết đặt trong `lower/sugar.rs` (`ha_to_json`) để giữ R1.
- **Một lõi so sánh**: `builtin::sap_xep_theo_khoa(host, xs, f, desc, kieu, ten, span)` — khoá tính
  **một lần**/phần tử, sắp xếp **ổn định**, `desc` chỉ đảo comparator. Shell `sort_by` dùng
  `KieuKhoa::Moi` (`int/float/size/duration/percent/str`); `std.list.sort_by` dùng `KieuKhoa::ChiInt`
  ⇒ **giữ nguyên** hợp đồng tĩnh `FnIntInt` + thông điệp lỗi cũ. **Nợ**: khoá `str` cho
  `std.list.sort_by` (chưa mở, cần task riêng).
- **Đo**: **704 → 718** test (+**14** `json_sort.rs`) + **3 fixture** `test/cmd/json/{json-pipe,

## ST-54 — `CODEGEN_TIN_TYCK` 21 → **0**

- **Dữ kiện quyết định**: HIR **không** mang dấu lỗi kiểu — walker trên 370 ca cho **0 nút
  `HExpr::Error`** / **0 kiểu `{error}`** (kể cả 318 ca hợp lệ), dù 21 ca có chẩn đoán front end.
  Vì vậy yêu cầu "từ chối khi HIR còn `Type::Error`" **không thể** làm bằng soi kiểu; phải đưa
  **chẩn đoán front end** vào cửa codegen.
- **Cửa duy nhất** `compile_kiem(hir, symbols, text, chan_doan)`: chẩn đoán `Severity::Error` đầu
  tiên ⇒ `Err(CodegenError::ChanDoan{short,dong,cot,msg})` (**đủ** mã + dòng:cột + thông điệp);
  cảnh báo (chưa có mã cảnh báo trong sổ) **không** chặn — ghi rõ "cửa chỉ chặn `error`".
  `compile()` cũ = `compile_kiem(..., &[])` (tương thích ngược); CLI `run --vm` truyền
  `loaded.diags` (defense-in-depth). Gặp `HExpr::Error` ⇒ `Err(Unsupported("error-expr"))`
  (trước phát chuỗi rỗng cho VM chạy "sạch").
- **Đo**: **718 → 730** test (+**12** `tin_tyck.rs`); `diag_cmp` chuyển sang `compile_kiem`, khoá
  **26/26 bị từ chối**, so **đủ** mã/dòng/cột/thông điệp; `CODEGEN_TIN_TYCK` **21 → 0**;
  `vis test` **370 ok**; allowlist **6**; gate **PASS** `2026-11-13T17:03:53Z`; đỏ trước: API chưa có.
