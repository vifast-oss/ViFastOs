### 3a. `v2/kernel/vifast-plat-common/tests/smp.rs`

Công thức thành **bốn** số hạng, và bổ sung phép kiểm **syscall stack** cho từng hart (trước đây
test chỉ kiểm tới `trap_top_offset` nên không thể phát hiện thiếu số hạng):

```text
$ git diff v2/kernel/vifast-plat-common/tests/smp.rs
-    // Mỗi record: guard 4 KiB + stack 64 KiB + trap stack 16 KiB; guard nằm ngay dưới stack của

+    // Mỗi record: guard 4 KiB + stack 64 KiB + trap stack 16 KiB + syscall stack 32 KiB; guard nằm
+    // ngay dưới stack của chính hart đó (tràn stack chạm đúng guard của hart mình — KT-49).
+    // KT-66 thêm **syscall stack** vào record ⇒ công thức **phải** có đủ bốn số hạng (KT-148).
     assert_eq!(
-        HART_GUARD_BYTES + HART_STACK_BYTES + HART_TRAP_STACK_BYTES,
+        HART_GUARD_BYTES + HART_STACK_BYTES + HART_TRAP_STACK_BYTES + HART_SYSCALL_STACK_BYTES,
```

Hai chỗ **cùng lỗi** trong cùng test, phải sửa cùng lúc (nếu chỉ sửa dòng 23 thì test vẫn đỏ ở dòng
sau — đã kiểm bằng cách chạy):

- `assert_eq!(trap_top_offset(MAX_HARTS - 1), HART_AREA_BYTES)` → `syscall_top_offset(MAX_HARTS - 1)`
  (đỉnh record giờ là đỉnh **syscall stack**, không phải trap stack).
- `assert!(trap_top_offset(hart) <= guard_offset(hart + 1))` → `assert_eq!(syscall_top_offset(hart),
  guard_offset(hart + 1))` — **siết** từ `<=` thành `==` (record liền kề, không hở), đúng luật
  D2-119 “cấm so sánh yếu khi đặc tả nói bằng”.
- Thêm hai assert mới: `syscall_bottom_offset(hart) == trap_top_offset(hart)` và
  `syscall_top_offset(hart) == syscall_bottom_offset(hart) + HART_SYSCALL_STACK_BYTES`.
